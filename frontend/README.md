# AI Chatbot

This is a simple AI chatbot project built with React for frontend and Node.js + Express for backend. The chatbot allows users to type a message, send it to the backend API, and receive an AI-generated reply.

## Features

- Clean chatbot UI
- User and bot message bubbles
- Dynamic input field
- Send message on button click
- Send message using Enter key
- Loading / typing indicator
- Auto scroll to latest message
- Backend API integration
- Secure API key handling using `.env`

## Tech Stack

### Frontend
- React
- Tailwind CSS
- JavaScript

### Backend
- Node.js
- Express.js
- CORS
- dotenv
- Google GenAI SDK
